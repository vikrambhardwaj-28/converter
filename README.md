# PDFCraft Studio Pro — Apple Pro Spatial Liquid Glass Suite (100% Client-Side)

> **एक शक्तिशाली, आधुनिक और 100% ऑन-डिवाइस प्राइवेट PDF व डॉक्यूमेंट स्टूडियो जो Apple macOS Sequoia और visionOS की लिक्विड ग्लास डिज़ाइन फिलॉसफी पर निर्मित है।**

---

## 🌟 प्रमुख विशेषताएं (Key Highlights)

- **🔒 100% ऑन-डिवाइस क्लाइंट प्राइवेसी (Zero-Server Upload)**: कोई भी पीडीएफ, इमेज या ऑडियो फाइल किसी बाहरी सर्वर पर अपलोड नहीं होती। सारी प्रोसेसिंग आपके अपने डिवाइस के ब्राउज़र (WebAssembly, Canvas, Web Crypto, Web Audio API) में होती है।
- **💎 Apple Liquid Glass & 3D Spatial UI**: macOS Sequoia & visionOS आधारित फ्रॉस्टेड ग्लास पैनल्स, 3D स्पैटियल कार्ड्स, स्पेक्युलर रिफ्लेक्शन और स्पैटियल प्लैटिनम / ओब्सीडियन डार्क मोड्स।
- **🎙️ Voice Writer & Universal AI Assistant**: किसी भी भाषा में बोलकर रियल-टाइम डिक्टेशन (Speech-to-Text) और विभिन्न टोन (Formal, Casual, Executive, Academic, Creative) में रीराइटिंग व ट्रांसलेशन।
- **🖨️ 300 DPI Studio Master Lossless Quality**: अल्ट्रा-शार्प रेंडरिंग, बिना किसी क्वालिटी ड्रॉप के हाई-रेज़ोल्यूशन एक्सपोर्ट।
- **📱 फुल मोबाइल व टैबलेट रिस्पॉन्सिव**: iOS Safari, iPadOS और Android पर 100% फ्लूइड टच इंटरफ़ेस और 44px+ ऐप्पल-ग्रेड टच टारगेट्स।
- **🛡️ एंटरप्राइज-ग्रेड सिक्योरिटी**: कड़े CSP (Content-Security-Policy) हेडर्स, XSS प्रोटेक्शन, डायरेक्टरी ट्रैवर्सल प्रिवेंशन और सुरक्षित फाइल हैंडलिंग।
- **🌐 द्विभाषी (Bilingual Support)**: 🇮🇳 हिन्दी और 🇬🇧 English में पूर्ण अनुवाद और सहज 1-क्लिक टॉगल।

## 🚀 कैसे चलाएं (How to Run)

### 1. रिपॉजिटरी क्लोन करें:
```bash
git clone https://github.com/vikrambhardwaj-28/converter.git
cd converter
```

### 2. लोकल सर्वर शुरू करें:
```bash
npm start
```

### 3. ब्राउज़र में खोलें:
**[http://localhost:3000](http://localhost:3000)** (या पोर्ट 3000 व्यस्त होने पर `http://localhost:3001`)

## 📦 प्रयुक्त तकनीक (Tech Stack)

- **कोर इंजन**: `PDF-Lib` (Native PDF generation, editing, drawing, stamping, encryption)
- **रेंडरिंग इंजन**: `PDF.js` (Mozilla's canvas rendering and text extraction with 300 DPI high-res scale)
- **डॉक्यूमेंट प्रोसेसर्स**: `SheetJS (xlsx)`, `Mammoth (.docx)`, `Marked (.md)`
- **आर्काइविंग**: `JSZip` (Client-side ZIP creation for batch page exports)
- **यूआई व डिज़ाइन**: Apple Liquid Glass, CSS3 3D Spatial Transforms, Lucide Icons, Google Fonts (`Inter`, `Dancing Script`, `JetBrains Mono`)
- **सर्वर**: लाइटवेट, जीरो-डिपेंडेंसी, सिक्योर Node.js HTTP सर्वर (`server.js`)
